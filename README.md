# Zinoxe Mod — Five Nights at Freddy's: Security Breach

Personal mods for FNaF Security Breach, with a launcher to install them, keep them up to date and pick which one to play.
Support and news: [Discord](https://discord.gg/yqKUMMkWhr)

*Français plus bas.*

## Install

1. Download `Zinoxe_Mod_Launcher_<version>.zip` from the latest [launcher release](https://github.com/Snokay/Zinoxe-Mod/releases) and unzip it anywhere.
2. Run `Zinoxe_Mod_Launcher.exe`. It finds the Steam copy of the game on its own (otherwise, click **Change** and pick the game's `Quarters` folder).
3. Click a mod, then **PLAY**. The mod is downloaded the first time, turned on, and the game starts through Steam.

The launcher installs UE4SS if the game doesn't have it yet. Only one mod runs at a time: the chosen mod is turned on in `ue4ss/Mods/mods.txt`, the other mods from this launcher and the Archipelago mod are turned off. **Normal game** turns them all off. Your other UE4SS mods are left alone.

Updates: the launcher checks GitHub when it opens. A new mod version shows an **Update** button (your rounds, options and scores are kept), a new launcher shows a banner at the top.

## Mods

| Mod | What it is |
|---|---|
| GeoGuessr in the Pizzaplex (`GeoGuessrSB`) | One player takes pictures of a spot in the Pizzaplex, the others have 10 minutes to find it. Press J in game. |

Made with the help of Claude (AI, Anthropic).

# Zinoxe Mod (français)

Les mods perso de FNaF Security Breach, avec un launcher pour les installer, les mettre à jour et choisir celui à jouer.
Aide et nouvelles : [Discord](https://discord.gg/yqKUMMkWhr)

## Installation

1. Télécharge `Zinoxe_Mod_Launcher_<version>.zip` dans la dernière [release du launcher](https://github.com/Snokay/Zinoxe-Mod/releases) et dézippe-le où tu veux.
2. Lance `Zinoxe_Mod_Launcher.exe`. Il trouve le jeu Steam tout seul (sinon **Changer** et choisis le dossier `Quarters` du jeu).
3. Clique sur un mod puis **JOUER**. Le mod est téléchargé la première fois, activé, et le jeu se lance par Steam.

Le launcher installe UE4SS si le jeu ne l'a pas. Un seul mod tourne à la fois : le mod choisi est activé dans `ue4ss/Mods/mods.txt`, les autres mods du launcher et le mod Archipelago sont coupés. **Jeu normal** les coupe tous. Tes autres mods UE4SS ne sont pas touchés.

Mises à jour : le launcher regarde GitHub à l'ouverture. Une nouvelle version d'un mod affiche **Mettre à jour** (tes manches, options et scores sont gardés), un nouveau launcher affiche un bandeau en haut.
